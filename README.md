## Passo 7 — Respostas do Quiz

**1) Qual é a finalidade da função `runApp` em uma aplicação Flutter?**
- **Resposta correta:** **B. Ela recebe um widget como argumento e o torna a raiz da árvore de widgets.**

**2) Como acionar uma recarga instantânea (Hot Reload) enquanto um aplicativo Flutter está em execução no terminal?**
- **Resposta correta:** **A. Pressione `r` no terminal.**

## Resumo da Prática Executada
- Criação do projeto mínimo via CLI (`flutter create birdle --empty`).
- Exploração da árvore de widgets (`MainApp` -> `MaterialApp` -> `Scaffold` -> `Center` -> `Text`).
- Execução no navegador e atualização instantânea de texto via **Hot Reload** (`r`).
